# Security

Report vulnerabilities privately. Do not open a public issue for a security report.

Email the repository owner, or use GitHub's **Private vulnerability reporting** if it is enabled on
the repo.

Please include:

- Affected package (`backend`, `web`, `mobile`, `@pairkit/core`)
- Impact (auth bypass, token leak, injection, etc.)
- Reproduction steps

We will acknowledge the report and work on a fix before any public disclosure.
